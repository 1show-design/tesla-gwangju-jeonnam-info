# 테슬라 전라남도 단톡방 운영원칙

테슬라 전라남도 오너들이 함께 모은 생활 정보, 최신 운영원칙과 이전 공지 요약을 모바일에서 쉽게 확인할 수 있도록 만든 정적 웹사이트입니다. 카페 확장이나 회원 유치가 아니라 기존 회원의 정보 공유를 목적으로 합니다.

## 공개 원칙

- 현재 운영원칙 시행일: 2026-09-13
- 과거 공지는 핵심 내용만 날짜별로 요약했습니다.
- 원본 PDF와 대화 CSV에 포함된 전화번호, 계좌번호, 회원 대화명 등 개인정보는 저장소에 포함하지 않습니다.
- 이 사이트는 Tesla, Inc. 또는 테슬라코리아의 공식 채널이 아닙니다.
- 검색엔진에 노출되지 않도록 `noindex` 메타 태그를 적용했습니다.

## 파일

- `index.html`: 운영원칙과 이전 공지 아카이브
- `styles.css`: 모바일 우선 반응형 디자인
- `app.js`: 카카오톡 공지문 복사와 규칙 펼침 기능
