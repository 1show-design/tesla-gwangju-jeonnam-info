# 테슬라 광주·전남 오너 정보방

테슬라 광주·전남 오너들이 함께 모은 생활 정보와 방 규칙을 모바일에서 쉽게 확인할 수 있도록 만든 정적 웹사이트입니다. 카페 확장이나 회원 유치가 아니라 기존 회원끼리 정보를 나누는 것이 목적입니다.

회원 카페: [$TESLA 오너스](https://cafe.naver.com/teslastocklife)

공개 사이트: [테슬라 광주·전남 오너 정보방](https://1show-design.github.io/tesla-gwangju-jeonnam-info/)

## 공개 기준

- 현재 방 규칙 시행일: 2026-09-13
- 원본 PDF와 대화 CSV에 포함된 전화번호, 계좌번호, 회원 대화명 등 개인정보는 저장소에 포함하지 않습니다.
- 이 사이트는 Tesla, Inc. 또는 테슬라코리아의 공식 채널이 아닙니다.
- 검색엔진에 노출되지 않도록 `noindex` 메타 태그를 적용했습니다.

## 파일

- `index.html`: 회원 정보실과 최신 방 규칙
- `drivelog.html`: TePilot 주행기록으로 장거리 경로를 짜는 방법과 회원용 AI 분석 절차
- `drivelog.js`: 주행기록 분석 프롬프트 복사 기능
- `styles.css`: 모바일 우선 반응형 디자인
- `app.js`: 카카오톡 공지문 복사와 규칙 펼침 기능
- `halloween.css`, `shops-halloween.css`: 할로윈 모드 색으로 바꾼 스타일(원본 `styles.css`·`shops.css`에서 자동 변환, 원본을 고치면 다시 만든다)
- `halloween-fx.css`, `theme.js`: 할로윈 장식(맨 위 장면·박쥐·카드 깜빡임·묘지 바닥)과 호박 단추로 켜기·끄기. 끄면 그 휴대폰에서는 원래 화면으로 보인다
- `hero-halloween.jpg`: 맨 위 장면. 테슬라 2026.38.3 업데이트 노트 이미지이며 출처를 화면에 적었다
